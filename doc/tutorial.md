# 从零使用个人知识管理助手

本文对应 1.0.0-rc.1，运行前准备 Python 3.12；本地关键词模式不需要模型Key、Node或图谱依赖。

## 01｜启动和保存第一份知识

按仓库 [README](../README.md) 建立虚拟环境并执行 `python app.py`，浏览器打开终端显示的本地地址。

点击“新建笔记”，填写标题、正文和逗号分隔的标签，点击保存。也可导入UTF-8 TXT/MD。相同正文会去重，重复导入不会复制资料。每份正文最多1MB，全库最多500片段。

点击左侧资料标题编辑。另一个窗口修改后，旧窗口保存会返回版本冲突并保留草稿；先复制草稿，再重新打开最新资料决定如何合并。标题/标签变化不重建图谱，正文变化或删除会让派生索引过期。

## 02｜查找和核对

搜索页默认“关键词（本地）”，只查SQLite中的资料原文，不发送模型请求。结果编号如 `[S12]` 对应片段，展开可读原文。

标签筛选仅用于资料列表；问答始终使用全部资料。聊天历史用于回看，旧消息不会自动注入下一轮，所以每个问题应自包含。

## 03｜开启图谱、多路检索和DSH

安装 `requirements-rag.lock` 和 `npm ci`，参考 `.env.example` 配置模型与Embedding，然后重启。DSH 使用 Messages 接口，图谱抽取和正文重排使用 Chat Completions；Embedding 的模型与维度必须匹配实际服务。

主动构建会把当前资料发给配置的服务。完成后在图谱页点击实体/关系查看来源。多路检索结合词法、向量和关系；DSH 可进一步查看schema并执行最多3跳的只读计划，再引用原文回答。

未配置/未构建/服务错误都会显示状态。只有“关键词（本地）”保证不调用模型；不生成最终答案的多路检索也可能收费。图谱抽取和模型回答需要核对原文。

## 04｜导出、备份和排错

“导出全部”下载正文Markdown与标签元数据ZIP，不包含聊天和派生索引。完整应用备份/恢复使用README中的维护命令，执行前停服；恢复目标存在时拒绝覆盖。

- 端口被占用：改 `--port`。
- 同库已有实例：关闭原应用或改 `--db`；不要删除仍被持有的锁文件尝试绕开。
- 图谱过期：确认服务配置后重建；构建时改正文会拒绝发布旧代。
- 服务不通：核对协议、地址、模型、Key和Embedding维度；错误并不说明知识库没有答案。
- 问答中修改资料：本轮可能返回 CORPUS_CHANGED，请在新资料上主动重试。
- 删除资料后旧答案仍有引用：这是历史快照；删除会话可清除其消息与轨迹，旧索引另用停服清理命令。

验收依据见 [Verify](VERIFY.md)；真实质量与模拟工程链路分开记录。
