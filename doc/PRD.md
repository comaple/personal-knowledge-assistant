## 01｜产品目标

建立个人长期使用的知识管理助手，让资料和笔记可以持续积累、有序组织、建立关联、随时找回，并用于解决问题。

主线：**收集 → 整理 → 关联 → 检索 → 使用 → 更新或导出。**资料库是主要入口，搜索、图谱与问答是使用知识的入口。日常操作在浏览器内完成，不要求用户理解数据库、索引或 DSH。

用户包括需要保存项目资料、阅读笔记、课程说明的个人研究者、开发者、内容创作者和自主学习者。首版满足一人本地使用，不设计团队协作。

## 02｜基线决策与范围

### 2.1 用户确认的方向

- 名称为个人知识管理助手，英文名 Personal Knowledge Assistant，目标为个人知识管理系统。
- 使用 SDD；先形成 PRD、Spec、Verify，再开展实现。
- 数据需要持久化；知识库采用知识图谱，RAG 采用多路召回。
- DSH 负责 Harness，交付实际接入说明与 GitHub 项目。
- 文档放入 `doc/`，技术方案围绕产品目标，不设置研究复现任务。

### 2.2 本轮确定的工程默认值

为达到可开发标准，本版将以下事项固定为首版默认值。这些是工程决策，不冒称用户逐项指定；后续可通过文档变更调整，无需在实现时重新猜测。

| 决策 | 首版基线 |
| --- | --- |
| 部署 | 本地单人浏览器应用，仅监听 127.0.0.1，无账号和云同步 |
| 资料类型 | UTF-8 TXT/Markdown 和系统内纯文本/Markdown 笔记 |
| 知识组织 | 标题、标签、资料列表；标签只筛选列表，不限制问答范围 |
| 完整闭环 | 笔记编辑、标签、知识导出纳入 P0，不再作为待定范围 |
| 智能能力 | 关键词、文本向量、图谱召回；DSH 调用只读知识工具回答 |
| 日常无 Key 能力 | 导入、笔记、标签、阅读、关键词搜索、历史查看与导出 |
| 初始容量 | 全库最多 500 个片段，每份资料最多 1,048,576 UTF-8 字节 |
| 编辑冲突 | 显式文档版本；过期编辑拒绝并保留用户未保存正文 |
| 数据保留 | 删除资料停止当前检索；历史引用快照保留；旧索引手动停服清理 |
| 质量门槛 | 使用 Verify 固定 20 题及明确阈值；不推迟到开发后临时决定 |

### 2.3 首版不包含

PDF/OCR、网页自动采集、附件、富文本、文件夹层级、完整编辑历史、自动摘要/自动标签、跨轮指代、多用户、云部署与同步、通用图查询语言、互联网搜索、增量图谱、后台任务断点续建。无自动物理彻底擦除承诺。

## 03｜核心用户流程

| 场景 | 操作路径 | 可见结果 |
| --- | --- | --- |
| 第一次使用 | 启动 → 导入 TXT/MD 或创建笔记 → 查看正文 | 原文、标题与保存状态可见；无需 Key |
| 整理知识 | 打开资料 → 改标题/正文 → 添加标签 → 按标签筛选 | 修改持久化；正文变更后提示图谱和向量需重建 |
| 查找原文 | 选择本地关键词或多路检索 → 提问 → 打开片段 | 显示实际通道、来源及降级原因 |
| 串联知识 | 配置服务 → 主动构建 → 查看图谱 → DSH 问答 | 返回跨资料证据和引用，可展开工具轨迹 |
| 更新资料 | 修改或删除 → 再搜索 → 查看旧答案 | 当前检索使用新资料；旧答案引用显示历史快照 |
| 带走知识 | 点击导出全部资料 → 下载 ZIP → 在系统外打开 | Markdown 正文与标题/标签元数据可读取 |

跨资料示例：摄影课说明指向青松教务，另一份服务说明给出退课需提前 72 小时。用户询问课程退课联系和期限，应得到两份原文支持的答案。完整固定资料见 [验收语料](fixtures/knowledge.json)。

## 04｜功能需求

所有下列需求均为首版 P0，验收编号与 Verify 一致。规格基线不代表已有实现已符合要求。

| 编号 | 功能 | 必须满足的行为 | 验收 |
| --- | --- | --- | --- |
| FR-01 | 资料导入 | 接收 UTF-8 TXT/MD；规范化正文、按内容去重、完整切块；空内容/非法类型/NUL/超限拒绝，写失败整体回滚 | AC-01 |
| FR-02 | 数据持久化 | 原文、笔记、标签、会话、消息、来源快照及已返回轨迹重启后可读；一轮消息和轨迹原子保存 | AC-02 |
| FR-03 | 本地关键词检索 | 明确的本地模式无需 Key、不调用任何模型；返回原文与来源，默认新问题使用此模式 | AC-03 |
| FR-04 | 索引管理 | 用户主动构建；显示任务和索引状态；资料正文/模型配置变化使旧索引失效；失败不覆盖可用代 | AC-04 |
| FR-05 | 多路检索 | 就绪时执行关键词、向量、图谱三路，去重并按正文重排；通道错误及重排失败明确降级 | AC-05 |
| FR-06 | 跨资料图谱查询 | 基于实际图结构执行有界计划，返回完整路径和原文；空结果允许预算内修正，不能编造路径 | AC-06 |
| FR-07 | DSH 问答 | DSH 实际检索后回答；引用必须属于本轮来源；资料不足明确说明，冲突资料并列展示，服务故障不说成无资料 | AC-07 |
| FR-08 | 图谱与原文阅读 | 可点击节点和边查看来源；图谱注明自动抽取、局部展示；历史答案打开当时快照 | AC-08 |
| FR-09 | 会话管理 | 创建/查看/删除会话，保存消息和工具轨迹；旧聊天不自动注入下一轮；不同会话相互独立 | AC-09 |
| FR-10 | 删除与过期保护 | 删除资料及当前片段/FTS/标签关联，使旧图谱和向量失效；新增资料不能复用旧来源身份 | AC-10 |
| FR-11 | 故障反馈 | 缺配置、服务错误、超时、版本冲突有具体提示；超时清理进程，修复后可再操作 | AC-11 |
| FR-12 | 安装与维护 | 干净检出可按说明安装和使用；提供配置、停服备份、恢复、索引清理与排错说明 | AC-12 |
| FR-13 | 笔记与资料编辑 | 创建笔记；编辑现有标题/正文；正文变更原子更新搜索并使派生索引过期；保存冲突不静默覆盖 | AC-16 |
| FR-14 | 标签组织 | 一份资料多个标签；替换标签、列表精确筛选；标签修改不重建全文索引、不改变问答范围 | AC-17 |
| FR-15 | 知识导出 | 无 Key 导出全部当前原文/笔记及标签元数据，内容属于同一快照；不包含 Key、会话或派生索引 | AC-18 |

## 05｜交互约定

- 导航包含资料库、搜索/问答、知识图谱；索引和服务状态可随时查看。
- 资料库显示标题、类型、标签、修改时间；按修改时间倒序，默认每页 20 条。编辑器有保存/取消，离开未保存正文时提示，失败或冲突保留输入。
- 标签筛选为单个标签精确匹配。页面明确显示“标签筛选仅作用于资料列表，问答使用全部资料”。
- 搜索模式为“关键词（本地）”“多路检索”“DSH 问答”；默认本地。多路检索和问答可能调用所配置的外部服务。
- 构建前展示资料发送范围和费用提示；用户点击构建才发起。服务配置通过本地配置文件维护，页面只显示可用性，不显示 Key。
- 资料删除需确认“停止当前检索，历史引用仍保留”；会话删除需确认其聊天和轨迹将一起删除。
- 搜索结果显示标题、片段与召回通道；答案就近显示引用、降级提示。执行轨迹默认折叠，避免干扰知识阅读。
- 空资料库、空搜索、无答案、资料冲突、索引过期、构建失败、服务不可用均有独立提示；不能只有一个通用失败弹窗。

## 06｜非功能需求与容量

| 编号 | 要求与通过标准 | 验收 |
| --- | --- | --- |
| NFR-01 | 本地访问；不向页面/响应/仓库泄露 Key；文档按文本显示，跨来源写请求拒绝 | AC-13 |
| NFR-02 | 模型只有四项知识库读工具；无 shell、任意文件写入、SQL/Cypher；资料内指令不改变权限 | AC-13 |
| NFR-03 | 规模和时间有上限：500 片段、问题 1000 字符、5 次 DSH 模型请求、150 秒整轮、30 分钟构建 | AC-14 |
| NFR-04 | 当前响应使用单一语料版本；不能混入删除/修改前证据；构建与保存失败无半事务 | AC-14 |
| NFR-05 | 目标提交、配置、语料与结果可追溯；模拟/真实验证分开；跳过项不算通过 | AC-15 |
| NFR-06 | 桌面 1440px 与手机 390px 可操作；无页面横向溢出；纯本地 API 在参考环境中 p95 ≤500ms | AC-15 |

参考环境为至少 4 个逻辑 CPU、16 GB 内存、SSD、Python 3.12、Node 24.9+；本地性能测量不含模型下载、外部服务、导出和图谱构建。具体采样方法见 Verify。

## 07｜首版成功标准

- AC-01—AC-18 全部满足约定；不得通过跳过依赖获得完整验收结论。
- 所有实际引用 ID 合法率 100%；过期来源被作为当前证据使用次数为 0。
- 固定题集：12 道有答案题至少 11 道找全所需证据、至少 10 道完整回答；4 道无答案题全部正确说明资料不足；4 道冲突题全部指出冲突并提供双方来源；全部 20 题无未受原文支持的事实断言。
- 维护者在干净环境完成导入、笔记、标签、检索、图谱/问答、重启、导出及恢复；导出可在系统外阅读。
- 有 Key 和无 Key 两条路径分别验证；真实服务未验证时只能标注工程演示，不能发布为完整首版验收通过。
