## 01｜任务执行规则

任务状态为 NOT_STARTED/IN_PROGRESS/DONE/BLOCKED；代码提交不自动等于 DONE。完成定义：对应规格实现、必要断言通过、证据可追溯、文档一致。若任务只完成 L2，记录其范围，不用任务完成替代最终真实质量验收。

先做 T00，再按依赖推进；同一会话内可自主解决实现细节，涉及产品/契约变化先修订基线。不得混入无关工作区文件、使用 git reset/clean 丢弃原型，或将原型现有行为当作已验收目标。
