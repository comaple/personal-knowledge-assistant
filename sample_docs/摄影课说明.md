# 青松摄影入门课（虚构教学资料）

本文件仅供这个软件项目练习，不是真实机构的课程政策。

## 课程安排
青松摄影入门课的课程事务由青松教务负责，授课负责人为林老师。
青松摄影入门课为期四周，每周六上午 09:00 至 12:00 上课。上课地点为教学楼二层 203 室。
第一周学习曝光三要素，第二周学习构图，第三周练习人像，第四周完成作品讲评。

## 退款规则
摄影课退款需要在开课前至少 72 小时申请。符合这一条件时退回全部学费；开课后不支持退款。
退款申请需要提供报名订单号和报名时的手机号。工作人员在收到完整申请后五个工作日内处理。

## 学习准备
参加者可以使用手机或相机。第一次上课前需要充满电，准备至少 5 GB 存储空间，并带三张自己拍摄的照片。
