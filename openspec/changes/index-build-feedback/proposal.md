# Proposal

## Why
点击构建后仅禁用按钮，索引仍显示尚未构建，用户无法判断是否启动或仍在处理。侧栏提示在手机被隐藏，功能准备条件和下一步也不明确。

## What Changes
- 后台报告准备、处理、校验发布、完成或失败阶段；处理计数来自真实LightRAG状态，不按时间伪造百分比。
- 主区域跨页面显示进度条、片段计数、耗时、连接恢复与完成/失败操作；刷新后继续跟踪运行任务。
- 解释保存资料、本地搜索、智能检索/问答之间的关系、前置条件和资料修改后重建要求。
- 不改变检索/问答算法，不重新发送用户资料做测试；保留用户正在进行的构建，更新服务前等待任务结束。

- 文档行支持仅构建本文，增量复用已构建且未变化的内容；智能通道只覆盖已构建范围，关键词仍覆盖全库。
- 新增API导航及无会话检索入口，复用资料写入入口供本机Agent调用。
- 用户导入时可自动用首两段/末一段生成显示名，失败保留原文件名；原文不变。

## Capabilities
### New Capabilities
- index-build-feedback：索引构建过程可观察性和就地使用指引。
- agent-knowledge-api：本机Agent无会话知识检索、资料写入及接口指引。
- document-display-titles：基于限定摘录的可选AI命名。
### Modified Capabilities
无；原有超时、单任务、原子发布及凭据边界继续有效。

## Impact
index_jobs.py、rag_backend.py、index.html、Job接口新增可选progress字段及doc中的契约/验收/教程。测试使用隔离资料与模拟服务；应用重启保留用户资料与已发布索引。API Key始终仅留本地。
